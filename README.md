# 🛍️ E-Kart MERN E-Commerce Platform

Live Demo: [https://mern-ecommerce-pooja.vercel.app/](https://mern-ecommerce-pooja.vercel.app/)

A full-stack MERN E-Commerce application with authentication, admin dashboard, cart management, online payments, analytics, responsive UI, and product management.

---

# 🚀 Features

## 👤 User Features

* User Registration & Login
* JWT Authentication
* Responsive UI for Mobile, Tablet & Desktop
* Product Listing & Product Details
* Search & Filter Products
* Add to Cart
* Checkout Flow
* Razorpay Payment Gateway Integration
* Order History
* Profile Management
* Upload Profile Picture

---

## 🛠️ Admin Features

* Admin Dashboard
* Sales Analytics Chart
* User Management
* Product Management
* Add / Edit / Delete Products
* Image Upload System
* Order Management
* View User Orders
* Protected Admin Routes

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/mern-ecommerce.git
```

---

## 2️⃣ Install Dependencies

### Frontend

```bash
cd client
npm install
```

### Backend

```bash
cd server
npm install
```

---

# 🔑 Environment Variables

## Backend `.env`

```env
PORT=8000
MONGO_URI=your_mongodb_url
JWT_SECRET=your_jwt_secret

CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret

RAZORPAY_KEY_ID=your_key
RAZORPAY_KEY_SECRET=your_secret
```

---

## Frontend `.env`

```env
VITE_URL=http://localhost:8000
```

---

# ▶️ Run Project

## Start Backend

```bash
npm run dev
```

## Start Frontend

```bash
npm run dev
```
